# how to
https://developer.mozilla.org/ja/docs/Web/CSS/Reference/At-rules/@font-face
これ参照して。
トップのディレクトリのcssに@font-faceっていうのを設定する必要がある。
```css

@font-face {

  font-family: "font-name";
  src: 
    local("font-name"),
    url("path") font-type("opentype")
}

```
みたいな感じで書く。上に書いてるものが優先される仕様。localはホストPCにインストールされていればそれを使用。UAが探してきてくれる
urlはCDNかプロジェクト内のパスを記述して直接フォントファイルを指定することで可能。

あとはそれぞれのページのcssでFont-familyをここで定義したfont-familyの名前にすれば適用可能。
