02 /

文字が「書かれる」仕組み

A / BASE

完成形の文字

12個の黒い <path> が、最初からSVG内にある。

B / MASK

白いなぞり線

16本の motion の線を <mask> 内で順番に伸ばす。白い部分だけが通る。

A × B / VISIBLE

文字が現れる

文字グループに mask="url(#text-mask)" を付け、線が通った範囲だけ見せる。

各線は pathLength: 0 → 1 で全長まで描かれ、strokeOpacity: 0 → 1 で白線が有効になる。親の staggerChildren: 0.1 が開始を100msずつずらす。線1本の描画時間は300ms。

AnimatedLogo.tsx：マスクの主な設定

const maskContainer = {
  hidden: {},
  visible: { transition: { staggerChildren: 0.1 } },
}

const maskStroke = {
  hidden: { pathLength: 0, strokeOpacity: 0 },
  visible: {
    pathLength: 1,
    strokeOpacity: 1,
    transition: {
      pathLength: { duration: 0.3, ease: 'easeInOut' },
      strokeOpacity: { duration: 0.1 },
    },
  },
}
03 /

ドットが次の動きを始める

最後のSVGパーツ

ドットはマスクの外にある独立した motion.path。表示開始から1.8秒後に、y: -230 → 0 と回転 -8 → 0 を0.2秒で動かす。

ドットの onAnimationComplete が親の App に完了を通知する。

Reactの状態切り替え

App は通知から550ms後に introComplete を true にする。これでロゴのクラスが is-intro から is-header へ変わり、ヘッダーにも is-ready が付く。

この1回の状態変更が、ロゴの移動と区切り線の待機を同時に始める。

App.tsx：完了を受けて状態を変える

<AnimatedLogo
  isHeader={introComplete}
  onDotAnimationComplete={() =>
    window.setTimeout(() => setIntroComplete(true), 550)
  }
/>
04 /

中央からヘッダーへ移る

ロゴの motion.div は最初からヘッダーの子要素。導入中は position: fixed で画面中央に置き、完了後は position: relative のフレックス項目としてヘッダー内に収まる。

layout を指定したMotionが、レイアウト変更時の位置と大きさを0.68秒でつなぐ。ヘッダーは display: flex と align-items: center で縦位置を決めるため、最終位置を top の数値で合わせる必要がない。

AnimatedLogo.tsx / AnimatedLogo.css：位置の切り替え

<motion.div
  className={`logo-stage ${isHeader ? 'is-header' : 'is-intro'}`}
  layout
  transition={{ layout: { duration: 0.68, ease: [0.16, 1, 0.3, 1] } }}
>

.logo-stage.is-intro {
  position: fixed;
  left: 50%;
  top: 50%;
  width: min(90vw, 942px);
  transform: translate(-50%, -50%);
}

.logo-stage.is-header {
  position: relative;
  width: 174px;
  flex: 0 0 174px;
}

520px以下の画面では、ヘッダーの高さが64px、ロゴの幅が150pxになる。SVGの viewBox="0 0 942.4 130" は図形の下側の余白を詰めるための設定。

05 /

区切り線はCSSで伸ばす

ヘッダーの ::after が高さ2.5pxの線。初期状態では scaleX(0)、is-ready が付いてから450ms待ち、520msかけて scaleX(1) にする。左端を起点にしているため、右方向へ洗われるように見える。

App.css：線の開始条件

.site-header::after {
  height: 2.5px;
  transform: scaleX(0);
  transform-origin: left center;
}

.site-header.is-ready::after {
  animation: header-divider-reveal
    520ms cubic-bezier(0.16, 1, 0.3, 1) 450ms both;
}
